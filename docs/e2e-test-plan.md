## 2. เครื่องมือ (`scripts/e2e/`)
- `reset.sh`: `down -v` → (BUILD=1 ⇒ build image) → `up db pgbouncer` → `db-apply.sh --seed` → `up api1 api2 lb` → รอ `/readyz` ทั้ง 3
- `lib.sh`:
  - `call [@api1|@api2] METHOD path [json] [header…]` → เก็บ status / body / header; ใส่ `X-Real-IP` สุ่ม `10.<ข้อ>.x.y` ต่อ call (throttle ไม่ปนกัน) เว้นแต่ระบุเอง

  - `expect_status N`, `expect_json '<jq>' <ค่า>`, `expect_msg "<ข้อความไทยทั้งประโยค>"`, `expect_header`
  - `sql "<query>"` (psql superuser ใน container db), `expect_sql "<query>" <ค่า>`, `as_app TENANT "<sql>"` (เป็น `an22_app` ผ่าน pgbouncer ตั้ง `app.tenant_id`)

  - ทุก check พิมพ์ `✔ <id> …` / `✘ <id> คาด … ได้ …`; ท้าย script สรุปจำนวน + exit ≠ 0 เมื่อมี ✘
- ตรวจร่วมทุกข้อ (ท้ายทุก script): access log ของ api1/api2 ช่วงที่รันไม่มี status 5xx (ยกเว้น case ที่ตั้งใจ), ไม่มี log ERROR ที่ไม่คาด,

## 4. สูตรที่ใช้คิดผลคาดหวัง
- **VAT รวมในราคา** ต่อบรรทัด: vat = amount − round2(amount ÷ 1.07); ยกเว้น VAT = 0; VAT บิล = ผลรวมบรรทัด
- **เงินสดปัด 0.25**: ต้องรับ = round(คงเหลือ ÷ 0.25) × 0.25; `rounding` = ต้องรับ − คงเหลือ; ทอน = รับมา − ต้องรับ; ไม่ใช่เงินสดต้องตรงยอด
- **ทุนเฉลี่ย** รับเข้า: round4((คงเหลือ × avg + จำนวน × ทุน) ÷ (คงเหลือ + จำนวน)); ตัดออก avg คงเดิม; COGS = round2(avg × จำนวน);
  serial = ทุนของเครื่อง (avg = เฉลี่ยทุนเครื่องที่อยู่ในคลัง ปัด 4); บริการ = ทุนมาตรฐาน × จำนวน (ไม่เดินสต็อก)
- **เลขเอกสาร** (วัน = วันนี้ Asia/Bangkok): `POS-<สาขา>-<เครื่อง>-YYYYMMDD-NNNN`, `TR- / CN- / EX- / INV-<สาขา>-YYYYMMDD-NNNN`, `SH-<สาขา>-YYYYMMDD-NN`, `SUB-YYYYMM-NNNN`
- **ข้อความวันที่**: `d/m/พ.ศ.` (billing / purge), ราคา `d <เดือนย่อ> พ.ศ.`
